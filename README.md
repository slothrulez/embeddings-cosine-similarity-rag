# Embeddings, Cosine Similarity & RAG

This is a Colab notebook I made while learning about embeddings and how they are used in semantic search and RAG.

I started with simple experiments like converting text into vectors and calculating cosine similarity, then slowly built on that to compare sentences, work with Gemini embeddings, split documents into chunks, retrieve relevant chunks, and pass the retrieved context to an LLM.

The notebook follows the things I tried while learning, so the code is kept fairly simple instead of turning it into a full framework or production implementation.

### Topics covered

* Text embeddings
* Sentence Transformers
* Vector representations
* Dot product
* Cosine similarity
* Comparing words and sentences
* Gemini embeddings
* Document chunking
* Embedding storage
* Similarity-based retrieval
* Basic semantic search
* Basic RAG
* Context-aware chunking experiments

Most of the explanation and experiments are inside the notebook itself.
